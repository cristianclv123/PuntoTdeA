Meta no alcanza localhost. Para pruebas necesitas un túnel HTTPS (Cloudflare Tunnel o ngrok) y para producción un dominio con proxy inverso y TLS. El verify token que registres debe coincidir con META_VERIFY_TOKEN.

{% icon 'file-text' size=18 %} Cómo configurar

Las credenciales se escriben en el archivo .env de la máquina, nunca desde el navegador.

1
Ejecuta el asistente, que pide los tres valores de Meta con entrada oculta y genera el verify token:
powershell -ExecutionPolicy Bypass -File .\configurar_meta.ps1
2
Si prefieres editarlo a mano, completa .env a partir de .env.example.
META_VERIFY_TOKEN=... META_APP_SECRET=... META_ACCESS_TOKEN=... WHATSAPP_PHONE_NUMBER_ID=...
3
Aplica los cambios. Las credenciales llegan como variables de entorno, así que hay que recrear el servicio; un reinicio deja las anteriores:
docker compose up -d --force-recreate web
4
Comprueba el estado y valida contra Graph API:
docker compose exec -T web python manage.py check_meta_whatsapp docker compose exec -T web python manage.py check_meta_whatsapp --validate

{% icon 'layout-template' size=18 %} Datos de demostración

Para probar el flujo de estados sin esperar a tener contactos reales.

docker compose exec -T web python manage.py seed_demo_whatsapp

Crea 8 contactos, 2 segmentos y 2 campañas: una con un destinatario en cada estado de entrega y otra en borrador para probar el envío real. Los wamid son sintéticos. Para borrar lo sembrado, añade --limpiar.

{% icon 'trash-2' size=18 %} Mantenimiento de eventos

Meta reporta cada estado de entrega por mensaje: con miles de destinatarios la tabla de eventos crece rápido. El comando es un ensayo por defecto.

docker compose exec -T web python manage.py cleanup_whatsapp_events docker compose exec -T web python manage.py cleanup_whatsapp_events --days 7 --ejecutar .\limpiar_retencion.ps1 -Days 7 -Si

Borra estados de envío antiguos (sent/delivered/read) y conserva los failed (motivo del error) y los mensajes entrantes del bot. No afecta los estados ya aplicados a los destinatarios. El script deja un log en logs/ y es apto para el Programador de tareas de Windows.
